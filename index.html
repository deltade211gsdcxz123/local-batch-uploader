Local Batch Uploader

Private desktop utility for the owner's own YouTube channels.

Privacy Policy Terms of Service

About

Local Batch Uploader is a private desktop application used only by its owner. It is not publicly distributed and is not offered as a hosted service.

Purpose

The application uploads local video files to YouTube channels that the owner personally authenticates through Google OAuth 2.0. It is designed to reduce repetitive manual upload work.

YouTube API Usage

The application uses YouTube Data API functionality for video uploads and, when enabled by the owner, playlist insertion. It does not provide public access to YouTube data and does not offer access to third parties.

Access

This is a local desktop application. There is no public web application, user registration, or public account system.
