Privacy Policy

Local Batch Uploader

Local Batch Uploader is a private desktop application used only by its owner. It is not offered to the public and does not operate a public user database.

Data Access

The application accesses YouTube account permissions only after the owner explicitly authorizes access through Google OAuth 2.0.

Data Stored

OAuth authorization tokens may be stored locally on the owner's computer so the application can continue to access the owner's authenticated YouTube channels. The application does not sell or share user data with third parties.

Data Use

Authorized YouTube access is used only to perform actions initiated by the owner, such as uploading videos and adding uploaded videos to playlists.

Data Deletion

The owner can remove locally stored OAuth tokens at any time from the application or file system, and can revoke Google account access from the Google Account permissions page.

Google Privacy Policy

Use of Google services is also subject to the Google Privacy Policy: https://policies.google.com/privacy

YouTube API Services

This application uses YouTube API Services. By authorizing access, the owner acknowledges that use of YouTube API Services is also subject to YouTube's Terms of Service and applicable Google policies.
